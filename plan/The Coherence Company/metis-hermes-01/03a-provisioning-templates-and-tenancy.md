# 03A. Provisioning, Templates, And Tenancy

## Purpose

Define how METIS makes agent setup easy, repeatable, and safely scoped.

## Topics to answer

- The unit of provisioning: project, organization, conversation, cohort, region, or workspace.
- The baseline template every new METIS agent should receive.
- The baseline template every new guide agent should receive.
- Which configuration surfaces should be declarative.
- Which defaults should exist so a new project can launch an agent with minimal manual setup.
- How project-level agents are related to child conversation-level agents.
- How names, identities, and state directories are generated and managed.
- How agents are cloned, forked, archived, paused, or deleted safely.
- What tenancy boundaries are required between The Gathering global, The Gathering local, The Coherence Company, ARK, and future collaborations.

## Included answers from current materials

- The core product to design is a reusable METIS framework for setting up agents easily across many projects.
- A major open question is the minimal METIS agent template that works across projects without becoming too generic.
- A major open question is the minimal guide-agent template that works across an event, an organization, and a workstream.
