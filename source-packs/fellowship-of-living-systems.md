## 2. Desired value
- **What would make the ARC Agent useful to FLS?** A shared, legible commons where partner organisations and builders coordinate as peers — state everyone can see and every agent can read/write — without a central gatekeeper, plus a governed handoff to stronger reasoning for the hard questions.
- **Most relevant coordination problem:** Implementation partners repeatedly re-solve the same problems because there's no shared, queryable state — knowledge sits in private silos, so people re-ask instead of reading a common board.
- **Who should receive value first:** Organisation representatives and technical contributors coordinating across the collective.
- **What makes the experiment worthwhile even if partly manual:** Proving that a shared commons plus capability handoff visibly improves answer quality without rebuilding anyone's stack.
- **Most important concern to resolve first:** Keeping each participant's private and commercial context sovereign while sharing a common surface — membrane, not membership. (This matters especially for a PBC holding IP.)

## 4. Public organisation profile
### Short profile
Fellowship of Living Systems (Food System Hackers PBC) is a Colorado Public Benefit Corporation that develops and holds the infrastructure for regenerative food-and-recovery systems — the patents, the implementation designs, and the operating IP. FLS treats waste as feedstock and living soil as anti-fragile infrastructure: distributed, mobile processing paired with regenerative practice, so communities can build the systems that feed and defend them rather than retrofit legacy ones. Its work spans soil regeneration, circular waste-to-value, and standing disaster-recovery capacity. FLS publishes an agent-readable canon for partners and builders. Learn more at livingsys.org.

### Main themes
- Living-systems / regenerative infrastructure
- Circular waste-to-value (waste as feedstock)
- Anti-fragile land and disaster-recovery capacity
- Patents and implementation IP
- Food-system resilience
