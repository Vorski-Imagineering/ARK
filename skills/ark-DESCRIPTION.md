# ARK

The ARK community agent's own capabilities.

Use these whenever someone asks about a participating organisation, asks to add
or approve one, or asks for the cross-organisation digest.

These skills run real commands against a corpus of approved public sources in
~/ark. They exist so answers carry citations to public URLs. Do not research an
organisation yourself and report the result — that produces an unsourced claim,
which is what this corpus exists to prevent.
