# Skill: ChatGPT Conversation Exporter

## What it does

Exports a full ChatGPT conversation to a single Markdown file.
All AI-generated images are downloaded as local PNG files and
referenced with relative local paths inside the `.md` file.

## Usage

1. Open any ChatGPT conversation in your browser
   (URL looks like `https://chatgpt.com/c/<id>`)
2. Scroll **all the way to the bottom** so all messages and images are loaded
3. Open DevTools → Console  (`F12` / `Cmd+Option+J`)
4. Paste the entire contents of `chatgpt-conversation-exporter.js` and press **Enter**
5. Accept the browser download prompts for all files

### Output
- `<conversation-title>.md` — full conversation in Markdown
- `image-01-<slug>.png` … `image-NN-<slug>.png` — AI-generated images

Put all files in the same folder — the Markdown image links are relative,
so any Markdown viewer (Obsidian, Typora, VS Code, GitHub) will display them inline.

| File attachments (PDFs, docs) | ❌ Not downloaded (no src exposed) |

## How it works

1. **Discovers images** — queries all `<img>` elements whose `alt` starts with
   `"Generated image:"`, deduplicated by `src`.
2. **Downloads images** — `fetch()` + `FileReader` → base64 data URL →
   `<a download>` trigger. Filenames are slugified from the alt text.
3. **Builds Markdown** — walks every `[data-testid^="conversation-turn-"]`
   section. User turns use the `.text-message` element; ChatGPT turns use
   the `.markdown.prose` div and are converted via a recursive
   `nodeToMarkdown()` DOM walker.
4. **Saves the `.md` file** — Blob → object URL → `<a download>` trigger.

## Requirements

- Run on `chatgpt.com` (same-origin fetch for images)
- No external libraries needed — pure browser JS
- Works in Chrome and Firefox DevTools consoles

---

## Limitations

- The page must be **fully scrolled** before running so that React has
  rendered all virtual-scroll sections
- Token-gated image URLs are fetched same-origin; the script will not work
  if run from a different origin
- Voice-mode responses that have no text render only the short on-screen
  transcript stub (typically one sentence)
