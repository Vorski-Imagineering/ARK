# Proposal: Building the ARC Community Agent

The original combined proposal has been split so the enduring agent vision is separate from the temporary delivery event.

## Current documents

- [ARC Community Agent: Vision and Functionality](./arc-community-agent-vision.md) defines the agent's purpose, users, capabilities, operating model, governance, and longer-term direction.
- [ARC Community Agent Hackathon Proposal](./arc-community-agent-hackathon-proposal.md) defines the hackathon challenge, scope, MVP, format, roles, deliverables, success criteria, and decision process.

The vision document is the canonical source for what the agent should do. The hackathon proposal is the canonical source for how the first version will be built and tested.
